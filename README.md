# Pixiv Keyboard Pagination

A Chrome extension that adds keyboard pagination to Pixiv.

## Controls

| Key | Action |
| --- | --- |
| `←` | Previous page |
| `→` | Next page |
| `Ctrl + ←` | First page |
| `Ctrl + →` | Last page, up to page 1000 |

## Install

1. Open `chrome://extensions/`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this project folder.

The extension can also be packaged with Chrome's **Pack extension** command.

For development notes and tests, see [DEVELOPMENT.md](DEVELOPMENT.md).
